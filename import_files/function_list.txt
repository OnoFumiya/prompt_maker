function_list
- Navigation(arg)
  - Function to move to arg.
  - arg is selected from location_list.
  - The result is “SUCCESS” or “FAILED”.
- GraspObject(arg)
  - A function that grasps arg.
  - The arg is selected from the object_list.
  - The result is “SUCCESS” or “FAILED”.
- PlaceObject()
  - Function to place the object you are holding on a table or desk.
  - No arg.
  - This function is performed after Navigation() to the table or desk where you want to place it.
  - The result is “SUCCESS” or “FAILED”.
- PassObject()
  - Function to pass the object you have to the person.
  - No arg.
  - This function is performed after Navigation() to the table or desk where you want to place it.
  - The result is “SUCCESS” or “FAILED”.
- FindObject()
  - Function to search for objects in front of the robot.
  - No arg.
  - If there are multiple objects in front of the robot, [A,B,C,C,C] is returned in duplicate.
  - If there is no object to find, navigation to the next position is performed.
  - The result is a “list of objects” found in object_list.
- FindPerson()
  - Function to find if there is a person in front of the robot.
  - No arg.
  - The function has to go to each position to get information about the person.
  - The result is “None” if no person is found, and “Information about the person” if a person is found.
- Speak(arg)
  - Function to speak a sentence, where arg should be in English.
  - arg is assumed to be in English.
  - This voice can only reach the person in front of you, so you need to navigate to the position where the person is if you want to speak.
  - The result is “SUCCESS” or “FAILED”.
- Listen(arg)
  - Function to recognize speech for arg seconds.
  - arg is an integer.
  - Like the Speak function, it can recognize the voice of the person in front of the robot, so it is necessary to navigate to the person who speaks.
  - The result is the “characters heard” during that time.
- End()
  - Function to be called when all the contents of the imperative statement have been completed.
  - No arg.
  - This resets the instruction.
